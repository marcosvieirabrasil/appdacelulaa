# App da Célula

App web para preparar encontros de célula com dinâmicas, versículos diários e ideias para palavras.

## Recursos

- 58 dinâmicas pesquisáveis, sorteáveis e salvas no navegador
- 121 leituras-base diárias para palavras de célula, sem repetição dentro de 90 dias
- Roteiro visual do próximo encontro
- Design responsivo em preto, laranja e glass

## Publicação

O site está publicado em https://dinamicas-de-celula.m4rcosvieirabrasil.chatgpt.site/

A configuração de hospedagem está em `.openai/hosting.json` e os arquivos estáticos em `dist/`.
